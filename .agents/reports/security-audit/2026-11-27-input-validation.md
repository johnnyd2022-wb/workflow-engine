The review covers the locally registered application and staff routes, with targeted regressions for findings and browser checks for changed forms. Existing database rows were left as stored. The audit branch includes the Xero tenant-isolation changes from !771.

## Semgrep

The baseline scan produced 23 matches and zero scan errors. The new input-validation rule accounted for all matches, at eight distinct reads in auth and one in organisation routes. Multiple field reads can produce repeated matches on the same body-read line. These are review leads for JSON object shape. This rule does not determine whether individual fields satisfy domain constraints. The learned-rule verifier confirmed that the new rule detects the unchecked fixture and stays silent on the checked fixture.

The frozen dependency audit reported no known vulnerabilities or adverse statuses across 122 packages. The focused Chromium tests ran over local TLS. One logout test failed in a combined browser run and passed on an isolated repeat and on the baseline. The Google invite test that compares a global user count passed serially after it failed while another local fixture changed the shared test database. The final production-source Semgrep scan found zero matches across 825 files with 32 rules. Gitleaks found no leaks in the branch commit range. The scan applies the repository rules and excludes ignored and oversized assets. Ruff and formatting checks passed.

## Coverage limits

- The static inventory omits controls created at runtime by feature flags, configured process prompts and JavaScript. Tests cover representative runtime states and the regressions listed above. The inventory cannot attest to every dynamically rendered control.
- A narrower request schema can refuse a legacy value when someone edits and resubmits it. This branch does not rewrite saved records or coerce them on reads. Relevant examples are historic task names, timestamps and over-precision quantities.
- Existing compatibility checks cover decimal strings. Exact unquoted decimal literals across storage boundaries remain open as VAL-FINAL-04.
- Shared-database failures reproduced on the earlier baseline include 44 Planning tests, 14 Customs premises counts, three evidence tests and one wastage test. The final private database avoids carrying those rows forward. The results of the final suite and GitLab checks are recorded on the merge request.
