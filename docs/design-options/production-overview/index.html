Production overview: five directions

Static mockups on the same data. Each changes navigation, layout, type, colour, shape and motion. Resize the window to see phone layouts; switch your OS to dark mode for the dark themes (all five have one).

  1. 1LedgerCalm fintech. Quiet left sidebar, one KPI strip with sparklines, a sortable table, attention list on the side. Inter, indigo.
  2. 2GlassLiquid-glass controls over a soft colour field: a floating nav strip, glass toolbar and action dock; content on solid frosted panels. Manrope, blue/cyan.
  3. 3BentoA bento grid: one big tile for the batch that needs you most, with its action on it; smaller tiles each carry a number and a tiny chart. Onest, blue on Apple grey.
  4. 4FlowKanban by stage. Floating pill nav, soft rounded cards that lift, attention as chips. Plus Jakarta Sans, violet/coral.
  5. 5MidnightProduct-dark like Linear and Raycast: batches grouped by stage, the selected one open in a detail panel with its steps and Record button. Inter + Geist Mono, violet. Light theme too.
