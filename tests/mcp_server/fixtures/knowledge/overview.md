Biz-E models a producer's work end to end. Raw materials arrive as lots. A workflow (a product's recipe) is run as a batch, whose steps consume lots and create intermediate and finished lots. Every lot keeps the batch and step that made it, so any lot can be traced back to its sources and forward to the invoices that sold it. Physical quantity is not the same as usable stock: ready dates, expiry and holds decide what can be used. Costs are actual, estimated or unknown, and unknown is never zero. Compliance records and excise are built from the same lots and batches.
